# Design: Web Search 论文检索改进

## 目标读者

负责按用户指定主题开展联网论文检索的 AI agent；用户需能在检索开始前审阅检索词。

## 章节结构与逻辑

更新现有 `web-search` skill，不新增独立文档。按以下层次组织：

1. **论文主题检索确认门禁**：明确检索前提、需展示给用户的关键词/检索式/范围，以及允许跳过确认的例外。先确认意图再检索，避免主题偏差。
2. **学术来源定位与组合策略**：说明 OpenAlex 是跨来源学术索引、arXiv 是预印本仓库；来源互补而非简单的“谁更全”。按主题和需求选源，必要时并行补检。
3. **全文获取边界**：区分元数据/摘要检索与论文全文下载；记录是否可获取全文及其官方/开放仓储链接，不承诺索引服务提供全文。
4. **OpenAlex 网络诊断**：OpenAlex 脚本默认直连；失败时分别测试 API 直连和代理；将本机观测写成非永久事实，不将端口监听、Google 可达性等价为 OpenAlex 可用性。
5. **检索结果交付**：列出题名、作者、年份、来源、摘要/相关性、URL，并说明筛选范围、去重方式和覆盖局限。

整体动线为“确认检索意图 → 选互补来源 → 检索/筛选 → 核实全文 → 透明报告”。

## 每节表达与结论

- 确认门禁：用户确认检索词后才发请求；用户已明确授权直接检索时可跳过。
- 来源策略：OpenAlex 广覆盖聚合索引，arXiv 覆盖其预印本库；不笼统宣称任一方更全，按主题互补使用。
- 全文：OpenAlex 记录和摘要不等于可下载全文；获取能力依开放获取状态及记录链接。
- 网络：优先直连 OpenAlex 是当前本机观测下的默认建议，而非对未来网络的保证；逐目标诊断，错误需如实反馈。
- 交付：引用可核验 URL，明确检索范围与限制。

## 引用关系与职责边界

- 修改对象仅为 `~/.agents/skills/web-search/SKILL.md` 中学术检索流程和 OpenAlex 网络/能力说明。
- 与 `papers` skill 的边界：后者负责本地论文库 CRUD；联网学术搜索策略归 web-search skill。
- 不修改脚本行为或声称已验证全网覆盖量。

## 外部调研知识点

无需新增外部领域断言。关于 OpenAlex 与 arXiv 的定位采用保守描述；不写未经实测的数量比较、覆盖率排名或全文下载保证。若未来需要量化某主题覆盖率，应设计同一检索式、同一时间范围的实证对比并记录方法。
