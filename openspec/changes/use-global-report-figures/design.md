## Context

见[提案](proposal.md)。本地与全局的绘图脚本及模板内容一致；现有差异只是调用路径和项目报告说明。项目仍须管理自己的文件落点。

## Goals / Non-Goals

全局负责制图；项目负责图源、成品、报告和大媒体存放规则。保持现有图片访问、渲染和资料不变，不迁移任何项目数据。

## Decisions

1. 在 `.agents/skills/documentation/SKILL.md` 明示全局制图入口，保留文档资产落点，并接收旧技能中的报告图、大媒体、可编辑图源、项目脚本约定。全局工具不承载项目路径。
2. 删除 `.agents/skills/report-figures/` 已跟踪的副本；不触及被忽略的用户文件。`.claude/skills` 仍解析到同一项目技能根。先完成文档，再删除副本，两步不并行；验收由主代理检查本地索引、全局脚本路径与候选名称。
3. 核对脚本同源和 Shell 语法；不重新渲染现有图，不安装 Python 或浏览器依赖。若无法跑全局绘图测试，明确记录依赖缺口，不将静态检查描述为渲染成功。

## Risks / Trade-offs

通用入口依赖用户已安装全局技能。若安装缺失，明确提示安装，不保留仓库副本作为回退。
